# Kindroid vs Nomi — AI Companion Comparison

Browser tools for character chat. Compare options for one thread you can return to. Independent overview. Prices and features change.

---

### Side-by-side

| Feature | Free | Paid |
| --- | --- | --- |
| Messages | Limited | Higher or unlimited |
| Characters | Restricted | More |
| Images | Limited or none | Available |
| Voice | Limited or none | Available |
| Memory | Shorter | Better |
| Filters | Stricter | Fewer on most plans |

Both are browser-first tools focused on character threads rather than general assistants.

---

### How people use them

1. Open the site.  
2. Pick a ready character or open the builder.  
3. Set a name, look and short background if building.  
4. Send test messages.  
5. Stay in the thread for continuity.  
6. Upgrade when free messages end.

### Checks before paying

- Exact free message count.  
- What paid unlocks (chat volume, images, voice).  
- Image generation meter.  
- Renewal price.  
- Cancel path.  
- No real personal data in chat.
